- **Calendar sync no longer shows tasks an hour late in some calendar apps.** A task without a time zone of its own is now written at its time in the calendar's time zone instead of as a floating time, which some web clients read as UTC. Existing events are written again once at the next sync (#2084). An event at a repeated local time (the hour clocks go back) is now read as its first occurrence, as other calendar apps do, so it can show one hour earlier than in 1.7.0.
