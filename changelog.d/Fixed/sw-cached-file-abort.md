- **The app no longer opens to a blank page now and then in Chromium.** The service worker handed the browser its stored copy of a file directly, and Chromium could drop that copy mid-read when the worker cleaned up its memory: one of the app's files failed to load and the page stayed empty with no error. The worker now reads each stored file whole before answering, and a copy it cannot read comes from the server instead (#1363).
