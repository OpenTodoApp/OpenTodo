- **A new device's first sync no longer freezes the list for a moment.** Reading every task again and drawing the list ran as one block of work of 200 ms or more on the Inbox, so the screen stopped responding for a moment while a new device synced. Reading and drawing now run one after the other, and the longest pause on the 10,000-task benchmark dropped from about 240 ms to 140 ms on desktop.
