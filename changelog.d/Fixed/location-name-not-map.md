- **A location can be a name that is not on the map.** Typing "Garage" or "Mum's" could not be saved unless the map search found it, so a place with no address never stuck (#817). The location field now offers **Use “Garage”** first; Enter keeps that name, with no address and no pin. An address the search finds stays in the list under it. Saved locations are unchanged. See [Locations](docs/locations-and-places.md).
