- **Opening and downloading attachments work on iPhone again.** In Safari and the Home Screen app, tapping an attached image or PDF did nothing, and so did Download, or opening a file the browser does not show (a zip, a document), for a file this device did not hold: each started only after the file was read or looked up, and Safari blocks what starts after the tap. They now start with the tap, and an image or PDF shows once it is ready.
