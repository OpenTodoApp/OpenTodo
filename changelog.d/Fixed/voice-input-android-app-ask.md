- **Voice input in the Android app can ask for the microphone.** The app never declared the microphone, so Android showed no prompt and no switch in the app's settings, and the page told you to allow it from an address bar the app does not have. The first time you dictate, Android asks; allow it and the page can record. A refusal says to allow the microphone for OpenTodo in the phone's settings.
