- **A task's right-click menu opens complete and stays where it appears.** The menu was shown before it had read the task it was opened for, so its first frame lacked the task's own items (Add to focus, Start tracking, Start focus), which then appeared and pushed the menu to another place. It now opens once those local reads have landed, a few milliseconds later, with every item and in its final place; the same holds for the row's More button, the keyboard's menu and the Selection bar's Actions (OpenSpec `context-menu-first-paint`). ([#840](https://github.com/OpenTodoApp/OpenTodo/issues/840))
