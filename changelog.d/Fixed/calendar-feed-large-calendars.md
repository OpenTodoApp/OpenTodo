- **Calendar feeds: a Google Calendar's secret address can be subscribed to.** A calendar is read as it arrives and only the events near the shown period are kept, so a calendar may now be up to 32 MB (was 2 MB) without the server holding it whole; a recurring event that started years ago still shows. A larger calendar says so and suggests calendar sync. ([Other calendars](docs/other-calendars.md#limits))
