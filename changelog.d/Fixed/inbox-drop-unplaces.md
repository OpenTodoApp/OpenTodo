- **Moving a task to the Inbox puts it in the Inbox.** Dragging a task onto Inbox in the sidebar, or choosing No project for it in the task panel, the list's edit bar or Move to project, now also clears its date, so a task added while Today was open (and given today's date) can be sent back to the Inbox. Before, the drop did nothing for such a task. A repeating task keeps its date, and the message says so. A task without a project that is not in the Inbox now reads "No project", in its panel and as the group heading in Today, Upcoming, Someday, Completed, label pages and saved views grouped by project ([#2137](https://github.com/OpenTodoApp/OpenTodo/issues/2137)).
