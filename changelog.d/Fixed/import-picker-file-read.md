- **Importing a file on a phone no longer fails with a false "offline" error.** A file chosen through the Android file picker is read into memory before it is sent, so picking a Todoist or other export on the Android app or a mobile browser imports as it does on the desktop; a file that genuinely cannot be read now says so instead of blaming the connection ([#1606](https://github.com/OpenTodoApp/OpenTodo/issues/1606)).
