- **The iPhone app opens when your server is down.** The App Store build used to need the network to start and showed an error when the server was unreachable; it now opens from its last copy in the web view's cache, shows the tasks it already holds, and syncs once the server answers again. A first launch, before the app has loaded once, still needs the network ([#1458](https://github.com/OpenTodoApp/OpenTodo/issues/1458)).
