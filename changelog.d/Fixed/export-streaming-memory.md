- **The account export no longer loads the whole account into memory.** `GET /api/v1/export` built every collection as one in-memory list and encoded the whole document at once, so a 50,000-task account made the server peak around 370 MB. It now writes the document a bounded page of rows at a time, keeping the peak near idle (about 70 MB on the 10,000-task fixture). The exported bytes are unchanged.
