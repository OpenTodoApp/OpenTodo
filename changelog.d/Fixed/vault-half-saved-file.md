- **A vault file being saved no longer loses its tasks.** An editor saves a file in two steps: it empties it, then writes the text. If `ot vault watch` or `ot vault sync` read the file in between, it took every task in it as removed, trashed them in the app and wrote the file over the save. An emptied file whose tasks turn up nowhere else is now left alone until the next sync reads the finished save.
