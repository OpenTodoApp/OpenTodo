- **A vault file being saved no longer loses its tasks.** An editor saves a file in steps: it empties it, then writes the text. If `ot vault watch`, `ot vault sync` or the Obsidian plugin read the file in between, it took every task in it as removed and trashed them in the app. A file read empty or part way through a save is now left alone for up to five minutes, then the finished save is read. A file whose project id was damaged keeps its project.
