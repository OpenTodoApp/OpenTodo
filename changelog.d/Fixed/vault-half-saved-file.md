- **A vault file being saved no longer loses its tasks.** An editor saves a file in two steps: it empties it, then writes the text. If `ot vault watch`, `ot vault sync` or the Obsidian plugin read the file in between, it took every task in it as removed, trashed them in the app and wrote the file over the save. An emptied file is now left alone for one sync, so the next sync reads the finished save.
