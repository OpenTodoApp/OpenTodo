- **Imports refuse oversized CSV fields and deeply nested JSON.** A file within the upload size and the 50,000-row limit could still hold one enormous field, a record with a very large number of fields, or deeply nested arrays, costing far more memory than any real export. Every CSV import (CSV, Todoist, TickTick, Linear, Asana, OmniFocus, Notion) now refuses a field over 1 MiB, a record over 4 MiB or with more than 1,000 fields, and a JSON file, also inside a ZIP, nested more than 256 levels deep. The import answers **too large** with the limit and, for CSV, the line, and nothing is imported. Exports from supported apps stay far below these limits. See [Import](docs/import.md#jobs-limits-and-undo) (OpenSpec `importer-field-limits`).
