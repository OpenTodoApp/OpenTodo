- **First-run setup under a domain name asks for the setup code until a base URL is set.** While a server has no owner and no `OPENTODO_BASE_URL`, it cannot tell its own name from another site's name pointed at it, so a first registration addressed to a domain name now needs the one-time setup code from the server log, even with `OPENTODO_SETUP_CODE` off. Opening the server by its IP address, `localhost`, a name without a dot or a local name (`.local`, `.lan`, `.home.arpa`, `.internal` and a few others) needs no code, so a fresh Docker install works as before; with `OPENTODO_BASE_URL` set nothing changes. The setup screen says why it asks and offers the IP address or the base URL instead. See [The setup code](docs/self-hosting/docker.md#the-setup-code) (OpenSpec `host-check-without-base-url`).
