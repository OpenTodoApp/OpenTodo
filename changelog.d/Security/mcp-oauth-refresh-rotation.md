- **OAuth apps on the MCP endpoint get a new refresh token on every refresh.** The refresh token an app sent stops working once it has been exchanged, and if an old one is sent again, the server ends that connection: its refresh and access tokens stop working, the app has to be connected again, and the audit log records `mcp_oauth.refresh_reused`. Clients registered only for Google's connector addresses, which Gemini uses, keep one refresh token, because Google's guide requires it. See [OAuth clients](docs/mcp-oauth.md) (OpenSpec `mcp-oauth-refresh-rotation`).
