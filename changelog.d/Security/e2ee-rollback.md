- **End-to-end encryption: devices refuse older versions they can recognise.** A device, `ot` and the Obsidian plugin refuse an encryption key record older than the one they use, and they read a new ciphertext format, `enc:v2:`, that binds each value to the time it was written. A device refuses a `v2` value served inside an operation with another time, keeps its own value, and Settings → End-to-end encryption says how many items it kept. Apps still write the current format; a later release switches to `v2` ([#969](https://github.com/OpenTodoApp/OpenTodo/issues/969)).
