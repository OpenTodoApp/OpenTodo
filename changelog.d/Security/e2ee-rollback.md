- **End-to-end encryption: devices keep their own value when the server sends an older one they can recognise.** A device and `ot` notice an encryption key record older than the one they use when the server serves it unchanged (for example after a restore from a backup): they keep their own, Settings says so and offers to upload it again, and sync goes on. A device, `ot` and the Obsidian plugin read a new ciphertext format, `enc:v2:`, that binds each value to the time it was written. A device refuses a `v2` value served inside an operation with another time, keeps its own value, and Settings → End-to-end encryption says how many items it kept. Apps still write the current format; a later release switches to `v2` ([#969](https://github.com/OpenTodoApp/OpenTodo/issues/969)).
