- **Edit and Open details on every task row.** Pointing at a row shows **Edit** where **Show details** was; it opens the same editor as <kbd>F2</kbd>. A task's menu holds **Edit**, **Show details** and **Open details**, which opens the task as <kbd>Enter</kbd> does (its page or the side panel, by **Open tasks**). While the side panel shows one task, editing another row in the list leaves the panel where it is until you move to another row. **Show details** is still one key away with <kbd>→</kbd>.
