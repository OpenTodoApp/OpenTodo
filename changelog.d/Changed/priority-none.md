- **A task without a priority now reads as having none.** Priority 4, where every task starts, shows as "No priority": a faint Priority in the task panel and "None" in the priority picker, so you can see a task has no priority and choose None to take one away. The stored value stays 4, so filters, `p4` and the API are unchanged, and a name you gave level 4 in Settings → Priorities still shows instead.
