- **Completing tasks in a long list is faster, above all on phones.** A long list now lets the browser skip whole blocks of about 50 rows far from the screen, instead of deciding for each of 2,000 rows on every frame and every tap; screen readers still find every row in its one list. A completed row now leaves the screen by itself when its animation ends, so the list is drawn once per completion instead of twice. In the 2,000-task project of a 10,000-task account on a slowed phone, completing a task now responds in about 110 ms instead of about 220 ms.
