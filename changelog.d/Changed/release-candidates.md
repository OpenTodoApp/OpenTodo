- **Release candidates can be prepared and stay with testers.** `make release-prepare VERSION=1.0.0-rc.1` writes only the candidate's `CHANGELOG.md` section and keeps the changelog fragments, so each candidate lists everything since the last release and 1.0.0 gets one complete section. The store templates, docs and Helm chart stay on the last release. A candidate tag no longer publishes the Claude or Obsidian plugin. The gates are those of 1.0.0, except that the reference-device record and the screen-reader passes, which need the owner's phones, only warn on a candidate ([RELEASING.md](RELEASING.md#release-candidates), OpenSpec `release-candidates`).
