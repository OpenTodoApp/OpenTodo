- **The app downloads about a third as much on first install, and the server is smaller.** The server now sends the web app's scripts and styles gzip-compressed (4.6 MB instead of 14.3 MB for everything the app keeps offline), so installing it on a phone over mobile data is about three times quicker, and the binary and container image are about 11 MB smaller because they store those files compressed. Clients without gzip and byte-range requests get the files as before, and installed apps still check every file against the signed list.
