- **Assistants create labels in any workspace.** The MCP tool `create_label` and the agent route `POST /api/v1/labels` take an optional `workspace_id` (a workspace id or name), so a label made for a project in another workspace shows under that workspace's Labels and in its filters; without it the label goes to the default workspace as before. A label of the same name counts only within its workspace, and a label name on a task means the label of the task's workspace (#1222).
