- **Repeating tasks are marked in a synced calendar.** Calendar sync writes a repeating task as its next occurrence, so the calendar showed no sign that it repeats. Its event is now titled "🔁 Water the plants" in Google Calendar, iCloud, Outlook and every CalDAV calendar. The marker is removed when the event is read back, so it never renames the task, and deleting it in the calendar changes nothing.
