- **Wildcards in filters.** A `*` in a label, project or section name stands for any characters, so `@backlog*`, `##project*` or `section: "In *"` follow every matching name, including ones added later. `\*` is a literal star and `\\` a literal backslash, and a name that is exactly an existing label's, project's or section's name still means that one, so saved filters keep their meaning (#1967).
