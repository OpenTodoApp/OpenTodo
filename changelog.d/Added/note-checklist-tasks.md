- **Tasks from a note's checklist.** In a project note or a standalone note, `Ctrl+Shift+Enter` (`⌘+Shift+Enter`) or **Make tasks** in the `/` menu turns the checklist line, or every checklist line of a selection, into tasks read like quick add, in the note's project (the Inbox for a note without one); each line becomes a link to its task. In a task's note Make subtask now takes a selection too. One Undo takes back the tasks and the lines; at most 50 lines at once. A routine's Create tasks can **Link back to the note**, starting each new task's note with a link to the note its lines came from.
