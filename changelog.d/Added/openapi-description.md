- **An OpenAPI description of the whole API.** Every server serves it at `/api/v1/openapi.json` (OpenAPI 3.1, no sign-in, readable from any site), and each release attaches it as `openapi.json`. It is generated from the server's code, so it can't drift: every `/api/v1` route with its parameters, request and response bodies, authentication and errors, and the synced entities as shared schemas with their field descriptions. Generate a typed client with any OpenAPI tool, or import it into Postman, Insomnia or Bruno ([HTTP API](docs/api.md#openapi-description)).
