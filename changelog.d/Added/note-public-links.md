- Note pages: **Publish note page…** in a standalone note's menu publishes it as a read-only page anyone with the link can open, without an account, at `/n/<secret>` with an optional label and expiry. The page shows the title, when it last changed, the formatted text, images in place and files to download; links to other notes, tasks and projects show as their text. The note's header says **Published**, with **Copy a new link** and **Revoke**. Note pages run on the task page machinery (hashed secrets, private headers, a check on every request, the shared limit of 100 active pages and 20 publishes an hour), work for end-to-end encrypted notes through a key after `#` in the link (images and files left out), and are refused on a demo instance (note-public-links).
