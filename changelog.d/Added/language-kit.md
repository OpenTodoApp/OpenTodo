- **A kit for new languages, and community translations.** `node scripts/i18n/new-language.mjs <code> "<Name>"` scaffolds every file a language needs (the app's catalog, notification texts, the browser extension, the Android app, emails, an empty quick-add vocabulary) without offering it in Settings, and `make i18n-status` shows how far each language is on each of them. A translation that is at least 90 % done and has a named reviewer can ship as a community language: Settings lists it after the others and says that some text is in English. A Translation issue form asks for the language and its reviewer. See [Translating OpenTodo](docs/translating.md#adding-a-language-step-by-step).
