- **A home for habits.** A Habits screen (More, `g` then `Shift+H`) lists each habit with its colour, anchor, a thread of the last seven days, how many of the last seven you kept and a check button; Today shows due habits as a strip above its tasks instead of rows. **New habit** and **Make it a habit** start one in a single form, a tiny version counts on hard days and shows half filled, past days can be set to done, tiny, skipped or cleared, and **Graduate** retires a habit that has stuck while keeping its history. A strength score forgives a single miss, and nothing turns red. **Settings → Account → How you work → Habits** turns all of it off, which hides every habit control and deletes nothing.
