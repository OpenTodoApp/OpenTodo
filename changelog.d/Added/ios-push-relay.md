- **The OpenTodo push relay, and the server side of iPhone push through it (part 1).** A new binary, `opentodo-push-relay`, forwards content-free wake-ups to the iPhone app through Apple's push service: it stores nothing, logs nothing per request and builds every payload itself. On the server, the owner switch "iPhone push through the OpenTodo relay" is off by default and nothing reaches any relay while it is off; `OPENTODO_APPLE_RELAY` optionally overrides the relay's address and never turns it on. The iPhone app's setting follows in a later release.
