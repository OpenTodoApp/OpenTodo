- **Import iCalendar task files.** Settings → Data → Import now reads an `.ics` file of tasks, such as a Nextcloud Tasks export, with the same mapping as CalDAV: titles, notes, dates, priorities, completion, categories as labels, repeat rules and alarms. Subtasks (`RELATED-TO`) stay subtasks, whatever their order in the file, and the file becomes a project named after the list. (#1201)
