- **Questions to the assistant cost less.** Without a skill, the assistant starts with the tools that read and show, and asks for the write tools (with `propose_changes`) when you ask for a change; they come with its next step. A question that only reads sends about 40% less input in its first step (50 tool definitions, about 57 KB, down to 35, about 33 KB). Skills keep their own tools, and amending an open proposal offers the write tools at once. The same on the device of an encrypted account.
