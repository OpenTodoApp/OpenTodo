- **Routines work in one workspace, and conditions can say "not".** A routine can now be limited to one [workspace](docs/routines.md#a-routines-workspace): its trigger fires only for that workspace's tasks, it finds and creates only there, and it never moves a task into another workspace's project. A new routine starts in the workspace you create it in, and the When card reads "in Work"; routines you already have keep working in every workspace. A project of another workspace is now named with its workspace ("Website (Work)") instead of "a removed project". Project, section and priority conditions get **Is not**, and project and section **No project** / **No section**, so "when a task is added without a project, move it to Triage" is one routine. REST takes `workspace_id` and `not_in`, and the MCP routine tools take `workspace`. ([#1132](https://github.com/OpenTodoApp/OpenTodo/issues/1132), [#1134](https://github.com/OpenTodoApp/OpenTodo/issues/1134))
