- API and MCP tokens can be limited to chosen workspaces: Settings → API tokens → **New token** → **Workspaces: Only these**, `ot token create --limit-to <workspace>` or `POST /api/v1/tokens` with `workspaces`. Such a token reads and changes only those workspaces over REST and MCP, its new items land there, and routes over the whole account refuse it with `token_restricted` (token-workspaces, #1227).
