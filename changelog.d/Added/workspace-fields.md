- **Fields for a whole workspace.** Define a custom field once in Settings → Workspaces → General → Fields…, and every project of that workspace has it, listed first in the project's Fields… dialog under "From" and the workspace's name. Only the workspace's owner defines and sees them; the API, the assistant and MCP list them too. Fields shared with the other members of a workspace come later ([#2029](https://github.com/OpenTodoApp/OpenTodo/issues/2029)).
