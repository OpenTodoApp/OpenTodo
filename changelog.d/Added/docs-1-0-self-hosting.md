- **Docs for 1.0: a self-hosting handbook, a configuration reference, a contributor guide and a public roadmap.** The [self-hosting handbook](docs/self-hosting/README.md) takes an operator from an empty host to a monitored server in eight steps: install (every platform in one table), first run, reverse proxy and TLS (Caddy, nginx, Traefik), backups with a 10-minute restore drill, upgrading, monitoring, a hardening checklist and sizing from the measured budgets. The [configuration reference](docs/self-hosting/configuration.md) lists every `OPENTODO_*` variable with its default and an example; a test fails when the code reads one that is not listed. Every error code the server sends is in the [API](docs/api.md) table, checked both ways, and its *Checked examples* run against a test server on every change. The [contributor guide](docs/contributing/first-contribution.md) has seven how-tos, from a first contribution in 30 minutes to adding an importer, a language or a shared contract, and [CONTRIBUTING.md](CONTRIBUTING.md) says how pull requests are made and how AI agents are used on the project. The [roadmap page](docs/roadmap.md), also in Help under About, shows each change as shipped, in progress or planned, worked out from the repository at every build. The docs check now fails for a screen of the app that no guide explains, and an audit fixed settings paths, labels and language counts that had gone stale. (OpenSpec `docs-1-0`, #592)
