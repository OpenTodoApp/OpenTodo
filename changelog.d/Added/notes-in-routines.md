- **Routines work with your notes.** A routine can start when a note is created, edited (5 minutes after you stop writing) or gets a label, or run on the note you have open (its menu and the command palette have **Run routine…**). New steps find notes by project, labels, last change or words, create a note, add and remove labels, move, pin or trash notes, and turn a note into a task; Get note text, Add to a note and Clear a note take a note too. Five starters to build on: Weekly review note, Todo label to task, Checkboxes to tasks, Stale reference notes and Journal line. `POST /api/v1/rules/{id}/run`, MCP `run_routine` and `ot routine run --note` take a note. On an encrypted account, steps that read a note's text run on your device; label and project steps stay on the server.
