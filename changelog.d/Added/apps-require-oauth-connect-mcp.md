- **Apps that require OAuth can now connect to the MCP endpoint.** Google Gemini's Connected apps refuses a pasted token (*"Gemini requires standard OAuth for server connections"*), so the server now answers as an OAuth 2.1 authorization server next to `/mcp`: discovery documents, dynamic registration limited to Google's connector addresses, authorization code with PKCE, a consent dialog where you allow the connection, access tokens that stop working after an hour, and a refresh token that keeps Gemini linked. The owner creates a client in **Settings → Integrations → AI assistants → Apps that sign in with OAuth** and pastes its id and secret into the app; the secret is shown once. Every access token is an ordinary API token — it appears as `MCP: <client>` in **Settings → Integrations → API tokens** — and a client can be cut off by deleting it here. See [OAuth clients](docs/mcp-oauth.md).
