# Changelog

The add-on's version is the OpenTodo release it runs. A version with a fourth number, such as `0.12.0.1`, changes only the add-on and runs the same OpenTodo release. OpenTodo's own changes are in its [changelog](https://github.com/pixari/opentodo/blob/main/CHANGELOG.md).

## 0.14.0

- OpenTodo [0.14.0](https://github.com/pixari/opentodo/releases/tag/v0.14.0).

## 0.13.0

- OpenTodo [0.13.0](https://github.com/pixari/opentodo/releases/tag/v0.13.0).

## 0.12.0

- First version: OpenTodo [0.12.0](https://github.com/pixari/opentodo/releases/tag/v0.12.0) on Home Assistant OS and Supervised, for amd64 and aarch64. Options for the base URL, a setup token, open sign-up, trusted proxies and the log level; data in the add-on's own folder, included in its backups.
