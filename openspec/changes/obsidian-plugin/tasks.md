# Tasks

Depends on `obsidian-origin` being merged (the server must accept the kind). Server tasks run `go test ./...`; web tasks `npm test` and `npm run build` in `web/`; plugin tasks `make obsidian` (type-check, unit tests with vitest and a mocked `obsidian` module, the build and the size budget). `make check` runs before the last task is ticked.

## 1. Server: push-only exchange

- [x] 1.1 `internal/httpapi/sync_handlers.go`: when `features` holds `push_only`, apply as today, skip the pull, answer with the head cursor (`sync.Service` gains a cheap `Head(uid)`), `hasMore: false` and empty `ops`, `memberships`, `workspaces`. Verified by `go test ./internal/httpapi/...`: a push-only creation on an account with existing history returns no ops and the head cursor; a repeat counts duplicates; a viewer's op is listed as refused; no session is 401 and a `read` token 403 `insufficient_scope`; the other devices' event stream receives a wake-up. Implemented with the existing `sync.Service.Cursor(uid)` (the CalDAV CTag: the greatest seq of the caller's ops and purge markers) as the head, so no new `Head`; the refused fields' server values are not sent back either (the device keeps no rows). Tests: `internal/httpapi/sync_pushonly_test.go`.
