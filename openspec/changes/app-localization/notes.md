## Decisions taken while implementing

- `errorMessage` shows the server's own message in English (it can name the field) and the translated code message in other languages.
- Day-month dates in a non-English locale use Intl's own day-month form (`3. Nov.`, `3 nov.`, `3 de nov.`); English keeps the hand-built `3 Nov`. The worker copy does the same and is pinned to `lib/dates.ts` by a test.
- `TestErrorCodesFixture` fails when another change adds a code (`outgoing-email`, `calendar-feeds`): regenerate the fixture and add the code to `ERROR_MESSAGES` when rebasing.
