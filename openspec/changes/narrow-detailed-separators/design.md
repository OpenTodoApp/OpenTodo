## Decision

Reuse the existing task-group boundary marker and the soft border hairline. The Detailed selector can paint it at any desktop row width. One line still uses the 40 rem row container condition.

The phone list already has dividers suited to its cards. Adding them to the desktop group logic would change phone row boundaries and is outside this prototype. The hairline sits over the existing row, so it adds no height and cannot intercept a pointer.

## Impact

Presentation only, with no data, sync, dependencies or network changes. There are no additional controls, properties, scroll regions, sidebar destinations or shortcuts.
