## Why

Renaming a project or choosing its appearance currently requires opening it. The sidebar is where people already organise projects, favourites and labels. Issue #1127 extends the shipped `sidebar-polish` roadmap work.

## What Changes

- Offer Rename, Icon and Colour in the Projects and Favourites row menus for users who can edit the project.
- Edit project names in place in Projects. In Favourites, keep the name dialog used by the other items there.
- Put one icon and colour control beside the name in the sidebar's New project form.
- Put one colour control beside the name in the sidebar's New label form.

## Scope

Keep the existing creation defaults and form rows. Project and label creation elsewhere, new permission rules, additional form text and API changes are out of scope.
