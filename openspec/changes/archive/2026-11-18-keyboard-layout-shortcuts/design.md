## Design

Resolve typed bindings across eligible scopes before trying a physical fallback. Use the matched chord to arm sequence prefixes and pass it to actions that consume a digit. Keep the original event for modifier, focus and browser behavior.

Use KeyA–KeyZ for a non-Latin letter and Digit1–Digit9 for a printable non-digit. Preserve typed symbols and existing modifier checks. Composition and AltGraph do not trigger the fallback. On French AZERTY the unshifted number row can thus run numeric shortcuts from its physical positions.

No data fields, dependencies or controls change. The interface budget is unaffected.

Against `24580d840` with the same Linux build tools, first-load gzip increases from 710,813 to 710,950 bytes (+137 bytes), within the 712 KiB budget. The stripped Linux amd64 binary is 46,629,024 bytes on both builds.
