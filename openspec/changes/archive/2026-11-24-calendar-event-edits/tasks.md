# Tasks

Groups 1, 2 and 3 are Go and run in that order; groups 4 and 5 are web and run in that order; **the two chains are independent** and can be built in parallel by two agents against the REST contract in design D4 (a web agent uses a fake `api` in vitest, a Go agent never touches `web/`). Group 6 needs 1 to 3. Group 7 comes last. Run `make check` before ticking 7.5.

Verify backend tasks with `go test ./...` (or the named package) and frontend tasks with `npm test` and `npm run build` in `web/`.
