# Coming from GTD

Open Loops is inspired by GTD (Getting Things Done) and keeps its core: capture everything, clarify once, organise by what the next step needs, review weekly. It is not affiliated with David Allen or the David Allen Company, and it is simpler in places: three horizons instead of six, and contexts as ordinary labels.

| GTD | Open Loops | In OpenTodo |
| --- | --- | --- |
| Capture, collect | Catch | quick add <kbd>q</kbd>, email, share, voice, CLI |
| In-basket | Inbox | the Inbox |
| Process, clarify | Clarify | triage <kbd>g</kbd> <kbd>p</kbd> |
| Two-minute rule | Do it if it is quicker than filing it | <kbd>c</kbd> in triage |
| Organize | Place | project, date, start date, Waiting, Someday |
| Next actions | Next | the Next view <kbd>g</kbd> <kbd>Shift+N</kbd> |
| Contexts | Contexts | labels starting with `@` |
| Waiting for | Waiting | assigned to someone else, or Blocked by |
| Someday/maybe | Someday | <kbd>y</kbd> in triage, the Someday view |
| Tickler file | Later | a start date |
| Calendar (hard landscape) | Scheduled | due dates, Today, Upcoming, the calendar |
| Projects list | Projects | projects, and the review's project walk |
| Project support material | the project note | <kbd>Shift+P</kbd> |
| Areas of focus | Area | a project that holds projects |
| Weekly review | Weekly review | <kbd>g</kbd> <kbd>r</kbd> |
| Trigger list | Mind sweep | the review's second step |
| Horizons 3-5 (goals, vision, purpose) | not modelled | write them in a project note if you like |

Your existing `@context` labels become contexts automatically. If you used a "Waiting" label or a far-future date for someday items, switch to assigning or **Blocked by**, and to Someday: they keep those tasks out of the planning views.
