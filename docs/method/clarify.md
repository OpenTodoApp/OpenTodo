# Clarify

Decide once what each item is and what it needs. Clarifying turns "stuff" into decisions, so you never read the same item twice wondering what it means.

## Ask two questions

For each item in the Inbox:

1. **Is it something to do?** If not, trash it, or keep it as a note in a project.
2. **What is the very next step?** If it takes a minute or two, do it now and complete it. Otherwise give it a home: that is the next move, [Place](place.md).

If the item is really an outcome with several steps ("Paint the bedroom"), it is a project: create one, and make the first step its first task.

## Process the Inbox

Press <kbd>g</kbd> <kbd>p</kbd> (or **Process** in the Inbox header) to see one item at a time with one key per decision: <kbd>c</kbd> complete, <kbd>t</kbd> today, <kbd>s</kbd> schedule, <kbd>m</kbd> move to a project, <kbd>a</kbd> delegate, <kbd>y</kbd> Someday, <kbd>l</kbd> add a context label, <kbd>Delete</kbd> trash. See [Process the Inbox](../process-the-inbox.md).

## How often

Once a day keeps the Inbox small; the [Daily check](rhythms.md#daily-check) reminds you. An Inbox at zero is a good feeling, but the point is that nothing in it is undecided for long.
