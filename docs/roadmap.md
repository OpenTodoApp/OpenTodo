# Roadmap

Every item is an OpenSpec change. Its status comes from the repository when these docs are built, so this page matches the version you are reading:

- **Shipped in x.y**: archived, in that release.
- **In progress (n of m)**: n of its m tasks are done.
- **Planned**: specified, not started.

Why each milestone exists, and the order inside it, is in [ROADMAP.md](../ROADMAP.md). Ideas and requests go to [GitHub issues](https://github.com/OpenTodoApp/OpenTodo/issues).
