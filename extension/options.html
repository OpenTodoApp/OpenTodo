OpenTodo Capture

Enter the address of your OpenTodo server. The extension opens that server's capture screen for the current page. It stores only this address, holds no password or token and never contacts the server itself.

How Save works

How Save works

Create a full-access token in OpenTodo under Settings, Integrations, API tokens, and name it after this browser so you can revoke it on its own. It stays on this device: browsers never synchronise it.

Screenshots

"Add screenshot to OpenTodo" captures the visible part of a page and hands the image to your server's capture popup, where nothing is saved until you press Save. Handing it over needs access to your server's address, and only that address; the browser asks when you save it.
