# Store listing (en)

## Name

OpenTodo Capture

## Summary

Add pages, links, images, mail and selected text to your own OpenTodo server.

## Description

Capture a task without leaving the page you are on. Click the toolbar button or press Alt+Shift+O: a small popup holds one line with the page's title, the text you selected, and the page as the task's origin. Right-click a link, an image or a selection to start from that instead. On a message open in Gmail or Outlook on the web, the subject becomes the line and the sender the first line of the description.

Two ways to save, chosen in the options:

- Capture screen (the default): Save opens your server's capture screen, where you check the task and save it. The extension holds no token and sends nothing itself.
- Quick save: with an API token from your server, Save creates the task at once. While you type, the line is previewed as chips (date, project, labels, priority, reminders) in your account's language.

OpenTodo is open-source and self-hosted. The extension talks only to the server address you enter; it collects nothing and sends nothing to anyone else.
